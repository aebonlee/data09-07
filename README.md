## 실행 방법

**온라인에서 바로 쓰기: https://aebonlee.github.io/data09-07/**

내 PC에서 쓰려면 설치 없이 아래 두 방법 중 하나로 엽니다.

1. **파일로 바로 열기** — 이 폴더의 `index.html` 을 더블클릭해 크롬·엣지로 엽니다. 인터넷이 없어도 동작합니다(엑셀·PDF 라이브러리가 `vendor/` 에 들어 있습니다).
2. **간이 서버로 열기** — 폴더에서 `python3 -m http.server 8000` 을 실행하고 브라우저에서 `http://localhost:8000` 을 엽니다. 한글 글꼴을 CID 방식으로 넣은 PDF 는 이 방법이 더 안정적입니다.

처음 열면 데이터가 비어 있습니다. 대시보드의 **「예시 데이터 불러오기」** 를 누르면 시연용 가상 도면 12건·그룹 4개·ECN 2건이 들어가고, 화면 위에 「예시 데이터」 안내 띠가 표시됩니다.

- 도면 PDF 는 **브라우저 안에서만** 읽습니다(서버로 보내지 않음). 저장되는 것은 추출한 글자와 도면 정보이고, PDF 원본은 저장하지 않습니다.
- 데이터는 이 브라우저(localStorage)에만 저장됩니다. 보관·이동은 「설정 → 백업 내려받기(JSON)」로 합니다.
- 예시 파일(`samples/`, 모두 가상): 도면 PDF 3건(`예시데이터_HN-*.pdf` — 「도면 등록」에서 올려 보기), 열 이름이 다른 도면 대장 `예시데이터_도면대장.xlsx`(「도면 대장 엑셀 가져오기」의 열 맞추기 시연용)
- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 예시 파일 다시 만들기: `node scripts/make-samples.js`

## 1단계 구현 범위

기획서 v0.2 5장 기능 목록 기준입니다. 완료 = 이번 1단계 웹 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 도면 등록 (FR-01) | 완료 | PDF 1건·여러 건(끌어다 놓기), 파일명·등록상태 표시, PDF 형식·손상 확인, 파일명·해시·품번+REV 중복 경고 → 기존 파일 연결 / 신규 버전 선택. PDF 없이 직접 입력, 도면 대장 엑셀 가져오기(열 맞추기) |
| 정보 추출 (FR-02) | 완료 | 브라우저 안 PDF 글자 추출(pdf.js) → 품번·품명·REV·고객사·기종·사용처·회로 수·분기 수·주요 커넥터·키워드, 미리보기(페이지 선택)·원문 확인. 추출 규칙은 가정 — 실제 제목란 양식은 2단계 |
| 추출정보 수정 (FR-03) | 완료 | 모든 값 수정·저장, 칸마다 자동/파일명/추정/수정/미인식 표시, 미인식 경고, 수정값이 다음 분석에 바로 반영 |
| 유사도 추천 (FR-04) | 완료 | 원문 3.6 가중치(25/20/30/15/10) 총점·항목별 점수, 상위 1~5건, 비교 패널(공통점·차이점·점수 근거) |
| 가중치·임계값 설정 | 완료 | 5개 가중치·기준점수(초기 70, UI 시안 값)·후보 건수·비교 범위를 설정 화면에서 조정 |
| 그룹 확정 (FR-05) | 완료 | 기존 그룹 연결·후보 변경·후보 제외·신규 그룹 생성, 확정자·일시·판단 메모 이력 |
| 검색 (FR-06) | 완료 | 품번·고객사·기종·사용처·상태 조건 검색, 상단 통합검색(ECN 번호 포함) |
| ECN 연결 (FR-07) | 완료 | 설계변경통보서 1~4절 항목(기본정보·결재·변경 내용·적용 시점·재고 처리·수신 부서), 변경 전후 도면·REV·유사 그룹 연결과 역이동 |
| 변경자재 기록 (FR-08) | 완료 | 신규·삭제·대체·수량변경·사양변경, 전후 품번·사양·수량·단위, 증감 자동, 재고처리·담당부서·현재고, 변경자재 대장 화면 |
| ECN 영향도·부서별 조치 (양식 6절) | 완료 | 9개 검토 항목, 상태 자동(미검토·-·완료·일정 미정·지연·진행 중 — 양식 수식과 같은 규칙) |
| ECN 종결 확인 (양식 8절) | 완료 | 4개 항목 자동 판정 + 변경자재 담당부서 확인(원문 6.2), 종결 불가면 완료 처리 제한 |
| 수평전개 검토 기록 (양식 7절) | 완료 | 동일 그룹·유사 도면(기준점수 이상) 불러오기, 적용 여부·검토 결과 기록 |
| 유사 후보 적중 검증 (양식 14) | 완료 | 담당자 정답 그룹 입력 → 상위 3개 적중 여부·적중률(목표 70%) |
| 엑셀 출력 (FR-09) | 완료 | 3 유사도 분석 결과표, 4 도면 그룹 목록, 5 ECN 요약표, 6 변경자재 목록, 14 유사 후보 적중 검증표, 부서별 조치사항, 필터 결과, 양식 일괄 출력, 설계변경통보서 1건(받은 양식의 A~P 배치·병합) |
| 대시보드 | 완료 | 전체·미분류·검토대기·진행 중 ECN, 최근 등록 도면, 추천대기 도면, 지연·미완료 ECN, 빠른 실행 |
| 전후 BOM 자동 비교 | 다음 단계 | BOM 엑셀 형태 확인 후(기획서 10장 5번) — 지금은 주요 커넥터·전선 목록으로 부품 공용률 계산 |
| OCR 보조 | 다음 단계 | 스캔본은 「문자를 거의 찾지 못함」 경고 후 직접 입력 |
| AI 추출 보조 | 다음 단계 | 사내 외부 AI 사용 범위 확인 후(10장 10번) |
| 형상·회로 정밀 비교 (FR-10) | 다음 단계 | 지금은 회로 수·분기 수 근접도로 형상 10점 |
